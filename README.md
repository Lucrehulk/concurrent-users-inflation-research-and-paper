# concurrent-users-inflation-research-and-paper

Self study, research, and theory focusing on how CCU in video games can be inflated while retaining a low detectability.

This was just a fun project I wanted to do to work on developing rigorous theory and producing structured, logical thinking. I found this topic to be unique and relatively unexplored, so I figured I'd explore this. Took about two weeks to produce the paper and the simulation. See `./work` for the actual work content.

Project includes a typed up, semi-formal paper with real logic, along with a developed simulation (the logic for which is derived in the paper).
